Create `LICENSE` file on GitHub:

2. Click "Add file" → "Create new file"
3. Name it: `LICENSE`
4. Click "Choose a license template"
5. Select "MIT License" (recommended)
6. Click "Review and submit"
7. Commit the file

### 3. Add a .gitattributes (Optional)

Create `.gitattributes` to mark your project languages:

```bash
# Create .gitattributes
echo "* text=auto" > .gitattributes
echo "*.js linguist-detectable=true" >> .gitattributes
echo "*.jsx linguist-detectable=true" >> .gitattributes
git add .gitattributes
git commit -m "Add .gitattributes"
git push
```

### Setup Instructions

1. **Install Backend:**
   ```bash

   cp .env.example .env
   # Edit .env and add Gemini API key
   npm start
   ```

2. **Install Frontend:**
   ```bash
   cd client
   npm install
   npm run dev
   ```
