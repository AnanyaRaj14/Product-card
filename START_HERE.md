## ⚡ Quick Start (3 Steps)

### Step 1: Add Your API Key (30 seconds)
1. Get API key from: https://makersuite.google.com/app/apikey
2. Open: `server/.env`
3. Replace `your_api_key_here` with your actual key
4. Save the file

### Step 2: Install (2 minutes)
Open two terminals in this project folder:

**Terminal 1:**
```bash
cd server
npm install
```

**Terminal 2:**
```bash
cd client
npm install
```

### Step 3: Run (30 seconds)
**Terminal 1:**
```bash
cd server
npm start
```

**Terminal 2:**
```bash
cd client
npm run dev
```
